VESTATES DIESEL TRACKER: INSTALLING IT AS AN APP ON YOUR PC
============================================================

This folder is the app. Put it online once (free, on GitHub Pages) and your PC
can install it like a normal program: it gets its own icon on the desktop, in
the Start menu and on the taskbar, opens in its own window, and works offline.

------------------------------------------------------------
1. PUT THE FOLDER ON GITHUB PAGES (about 5 minutes, one time)
------------------------------------------------------------
 a. github.com -> New repository -> name it e.g. diesel-tracker -> Public -> Create.
 b. On the new repo page click "uploading an existing file", drag in EVERYTHING
    in this folder (index.html, sw.js, manifest.webmanifest and all the .png
    files) and click "Commit changes".
 c. Repo -> Settings -> Pages -> Source: "Deploy from a branch",
    Branch: main, folder: / (root) -> Save.
 d. After a minute your app is live at:
        https://YOUR-GITHUB-USERNAME.github.io/diesel-tracker/
    Upload the FILES themselves, not the folder, or that link shows "not found".

    The app itself holds NO readings or prices. All of that lives in your
    Firebase project, behind your sign-in, so the public link shows only a
    sign-in screen.

------------------------------------------------------------
2. INSTALL IT ON THE PC
------------------------------------------------------------
 Open the link above in Microsoft Edge or Google Chrome, then either:
  - click the green "Install app on this computer" button at the top of the
    side menu, or
  - Edge:   ... menu -> Apps -> "Install this site as an app"
    Chrome: the install icon at the right end of the address bar
            (or ... menu -> Cast, save and share -> Install page as app)

 It now opens from the desktop/Start menu like any program.
 Do the same on your phone (Chrome -> ... -> Add to Home screen).

------------------------------------------------------------
3. CONNECT FIREBASE (so the PC and phone share the same readings)
------------------------------------------------------------
 In the app: Settings -> Connect Firebase, and follow the 4 steps there.
 Also add your GitHub Pages address under Firebase -> Authentication ->
 Settings -> Authorized domains (YOUR-GITHUB-USERNAME.github.io).

 Then load the old tracker's history (one time):
   Settings -> Diesel history -> Import history file -> pick
   diesel_history.json (sent separately, NOT in this folder).
   Do not upload diesel_history.json to GitHub.

 Without Firebase, readings are saved inside that one app on that one PC.

------------------------------------------------------------
UPDATING THE APP LATER
------------------------------------------------------------
 Upload the new index.html to the repo (replace the old one), and in sw.js
 change VERSION = 'diesel-v12' to 'diesel-v13' (then v3, ...). The installed
 app picks up the new version the next time it opens with internet.
